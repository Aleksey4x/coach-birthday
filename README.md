# coach-birthday

Поздравительный лендинг для тренера от команды. Одностраничник, mobile-first, чистый HTML/CSS/JS.

## Структура

- `index.html` — разметка страницы (герой, поздравление, заслуги, галерея, видео, аудио)
- `css/style.css` — стили, mobile-first
- `js/main.js` — scroll-reveal анимации, управление аудио
- `assets/img`, `assets/video`, `assets/audio`, `assets/logo` — медиафайлы

## Локальный просмотр

Любой статический сервер, например:

```bash
npx serve .
```

## Публикация на GitHub Pages

Settings → Pages → Source: `main` / `root`.
